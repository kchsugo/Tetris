# 🎮Python Tetris Collection

이 저장소는 **Python**으로 구현한 다양한 방식의 테트리스(Tetris) 게임을 담고 있습니다.  
각 버전은 구현 구조와 철학이 다르며, 코드의 발전 과정을 보여줍니다.

---

## 📁 폴더 구조

| 폴더/파일     | 설명                         |
|:-------------:|:----------------------------|
| `src/`        | 테트리스 소스 코드 모음      |
| `docs/`       | 발표 자료(PPT, PDF 등)       |
| `README.md`   | 프로젝트 설명 파일           |

---

## 🕹️ 구현 버전 소개

### 1️⃣ 함수형(Function-based) 테트리스
- **설명:**  
  객체 없이 함수들만으로 구현한 가장 기본적인 테트리스입니다.
- **특징:**  
  - 간단하고 직관적인 구조
  - 함수 호출 중심
  - Python 입문자에게 적합

---

### 2️⃣ 클래스 기반(Object-oriented) 테트리스
- **설명:**  
  Python의 `class`를 활용하여 객체지향적으로 구현한 테트리스입니다.
- **특징:**  
  - 각 구성요소(블록, 게임판 등)를 클래스로 분리
  - 코드의 재사용성과 확장성 강화
  - 유지보수에 용이

---

### 3️⃣ 플러그인(Plugin) 방식 테트리스
- **설명:**  
  플러그인 구조를 도입하여, 기능을 자유롭게 추가/확장할 수 있는 테트리스입니다.
- **특징:**  
  - 외부 모듈이나 기능을 플러그인 형태로 추가 가능
  - 높은 커스터마이징과 확장성
  - 고급 사용자를 위한 구조

---
